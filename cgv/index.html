Conditions d’utilisation

1. Objet

Les présentes conditions régissent l’utilisation du site Prix Net Réel, édité par EVITEC LUX SARL-S.

2. Service gratuit

Le calcul détaillé, la comparaison de tes calculs, le PDF et les guides sont gratuits et sans inscription. Tes calculs sont enregistrés dans ton navigateur, sur ton appareil.

3. Assistant IA

L’assistant IA est offert pour 2 calculs par visiteur, sans inscription ; les calculs offerts sont limités par appareil et par connexion. Ensuite, il est accessible par abonnement, ou avec un code d’accès personnel remis par l’éditeur. L’assistant pose les questions et fait calculer le moteur ; ses réponses peuvent contenir des erreurs : vérifie chaque chiffre dans le calcul détaillé.

4. Abonnement

L’abonnement coûte 9 € par mois. Il donne accès à l’assistant IA pendant la période payée, dans la limite de 200 questions par mois ; le volume de traitement mensuel est aussi plafonné pour éviter les abus. Il se renouvelle automatiquement chaque mois. Le paiement est encaissé par Stripe à la souscription puis à chaque renouvellement ; en cas d’échec du paiement, l’accès est suspendu.

Après le paiement, le site t’affiche un code d’accès personnel : il sert à te connecter sur un autre appareil. Un code ne doit pas être partagé ; l’éditeur peut désactiver un code utilisé de façon abusive.

5. Résiliation

Tu arrêtes l’abonnement quand tu veux depuis « Gérer mon abonnement ». L’arrêt prend effet à la fin du mois déjà payé ; l’accès reste ouvert jusque-là.

6. Résultats

Les calculs reposent sur les données que tu saisis ou que tu donnes à l’assistant. Tu restes seul juge de tes prix. L’éditeur ne peut être tenu responsable d’une décision prise sur la base d’une simulation.

7. Droit applicable

Droit luxembourgeois.
