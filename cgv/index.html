Les tests rapides, le calcul complet, la comparaison de tes calculs, le PDF et les guides sont gratuits et sans inscription. Tes calculs sont enregistrés dans ton navigateur, sur ton appareil. Rien n’est vendu sur le site pour le moment.

3. Assistant IA (test privé)

Pendant le test, l’assistant IA est accessible uniquement avec un code d’accès personnel remis par l’éditeur, dans la limite du nombre de questions par mois affiché dans l’assistant. Le code ne doit pas être partagé ; l’éditeur peut le désactiver à tout moment. L’assistant pose les questions et fait calculer le moteur ; ses réponses peuvent contenir des erreurs : vérifie chaque chiffre dans le calcul complet.
