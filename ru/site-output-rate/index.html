Выработка, которая создаёт (или съедает) вашу маржу

Выработка — это сколько m² один человек выполняет за день. У каждого объекта есть минимальная выработка: ниже неё ваша цена уже не покрывает затраты.

Рассчитать свой случай с помощью ассистента

Как это считается

Полные затраты на объект пересчитываются для каждой возможной выработки (оплата труда, дни аренды лесов, поездки),
и ищется первая выработка, при которой затраты становятся ниже вашей цены.
Простая пропорция здесь не работает: материалы от выработки не зависят.

Пример с цифрами

Кровля 180 m² по 59,38 €/m² без НДС, плановая выработка 22. Минимальная выработка 13,30 (без рисков и комиссий в цене). Ваша бригада может замедлиться примерно на 40 %, прежде чем начнёт терять деньги.

Дорогие ошибки

  1. Считать по выработке удачного дня на лёгком объекте.
  2. Забывать о простоях: подготовка площадки, сворачивание работ, непогода, ожидание поставки.
  3. Никогда не замерять реальную выработку после завершения объекта.
